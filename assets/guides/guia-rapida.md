# Guía rápida — Micro-Herramientas impulsadas por IA

## Empezar en 1 minuto

1. Abre el dashboard y elige una categoría: **Creadores**, **Empleo** o **Negocios**.
2. Entra a una herramienta.
3. Escribe al menos **10 caracteres** en el campo de texto.
4. Pulsa **Generar con IA**.
5. Copia el resultado.

## Configurar la API

1. Haz clic en el icono ⚙️.
2. Pega tu API Key de [Google AI Studio](https://aistudio.google.com/apikey).
3. O activa **Modo de prueba** para probar la UI sin consumir cuota.

## Límite gratuito

- Tienes **3 generaciones por día** en el plan gratis.
- El contador se reinicia automáticamente al día siguiente.
- El botón 🔄 solo existe para pruebas locales.

## Atajos de teclado

| Tecla | Acción |
|-------|--------|
| `1` / `2` / `3` | Cambiar categoría |
| `T` | Tema claro/oscuro |
| `A` | Abrir configuración API |
| `/` | Enfocar el textarea (dentro de una herramienta) |
| `Esc` | Volver al dashboard |

## Consejos por categoría

- **Creadores**: sé específico con el tema, el tono y la plataforma.
- **Empleo**: pega el CV y/o la oferta reales; no inventes métricas.
- **Negocios**: describe producto, audiencia y resultado deseado.
