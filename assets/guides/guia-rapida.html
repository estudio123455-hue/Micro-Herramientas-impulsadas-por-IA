Guía rápida

Todo lo que necesitas saber para generar contenido con IA en menos de un minuto.

🚀

Empezar en 1 minuto

  1. 1

    Abre el dashboard y elige una categoría: Creadores, Empleo o Negocios.

  2. 2

    Entra a la herramienta que necesitas.

  3. 3

    Escribe al menos 10 caracteres en el campo de texto. Cuanto más contexto des, mejor el resultado.

  4. 4

    Pulsa Generar con IA y espera unos segundos.

  5. 5

    Copia el resultado con el botón Copiar o reintenta si el output no te convence.

⚙️

Configurar la API

  1. 1

    Haz clic en el icono ⚙️ en la barra superior.

  2. 2

    Pega tu API Key gratuita de Google AI Studio . Tu key se guarda solo en tu navegador, nunca en un servidor.

  3. 3

    O activa Modo de prueba para explorar la interfaz sin consumir cuota de API.

📊

Límite gratuito

  • Tienes 3 generaciones por día en el plan gratis.
  • El contador se reinicia automáticamente a medianoche.
  • El botón 🔄 solo existe para pruebas locales; no afecta al límite real.
  • Con tu propia API Key de Google, las generaciones solo están limitadas por tu cuota de Google AI Studio.
⌨️

Atajos de teclado

Tecla Acción
1 2 3 Cambiar categoría (Creadores / Empleo / Negocios)
T Alternar tema claro / oscuro
A Abrir configuración de API Key
/ Enfocar el campo de texto (dentro de una herramienta)
Esc Cerrar modal o volver al dashboard
💡

Consejos por categoría

🎬
Creadores

Sé específico con el tema, el tono y la plataforma (TikTok, Reels, Shorts). Cuanto más contexto, más accionable el guion o el gancho.

💼
Empleo

Pega el CV real y/o la oferta de trabajo. No inventes métricas; si falta un dato, el modelo te dejará un marcador visible para completarlo tú.

📈
Negocios

Describe el producto, la audiencia y el resultado deseado. Los emails y pitches mejoran mucho con contexto real del cliente o empresa objetivo.

¿Algo no está claro? El Modo de prueba es tuyo para experimentar sin coste.
